# LangChain

LangChain es un framework para desarrollar aplicaciones con modelos de lenguaje (LLMs). Proporciona componentes modulares para construir pipelines de IA.

## Instalación

```bash
pip install langchain
Componentes principales
Model I/O: Interfaz con LLMs

Retrieval: Recuperación de información

Chains: Secuencias de llamadas

Agents: Toma de decisiones autónoma

Memory: Persistencia de estado

Integración con RAG
LangChain facilita la implementación de sistemas RAG mediante:

DocumentLoaders: Carga de documentos

TextSplitters: División de texto en chunks

VectorStores: Almacenamiento de embeddings

Retrievers: Recuperación de información

Chains: Flujos completos de RAG
